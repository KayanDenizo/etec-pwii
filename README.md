# 🌐 PW II: ETEC Uirapuru

Atividades e projetos da disciplina **Programação Web II** (2025), do curso técnico em Desenvolvimento de Sistemas da ETEC Uirapuru.

| Atividade | Descrição | Tecnologias | Data |
|---|---|---|---|
| [`01-classe-aluno-pdo`](01-classe-aluno-pdo/) | Primeira classe com PDO: cadastro de alunos e páginas protegidas | PHP, MySQL, PDO | 08/2025 |
| [`02-login-cadastro-alunos`](02-login-cadastro-alunos/) | Cadastro e login de alunos com senha criptografada e diagrama de classes | PHP, MySQL, PDO | 08/2025 |
| [`03-licao-cadastro-alunos`](03-licao-cadastro-alunos/) | Lição de cadastro de alunos com orientação a objetos | PHP, MySQL | 09/2025 |
| [`04-mario-jump`](04-mario-jump/) | Jogo Mario Jump com detecção de colisão | HTML, CSS, JavaScript | 10/2025 |
| [`05-sistema-bancario`](05-sistema-bancario/) | Sistema bancário simples com contas e saldo | PHP, MySQL, PDO | 11/2025 |

> O app de clima feito nesta matéria tem repositório próprio, com site no ar: [climatempo-project](https://github.com/KayanDenizo/climatempo-project).

## Como rodar

Os projetos em PHP rodam no [XAMPP](https://www.apachefriends.org/): copie a pasta da atividade para `htdocs`, inicie o Apache e o MySQL, execute o `banco.sql` da atividade no phpMyAdmin e acesse `http://localhost/<pasta>/`. O Mario Jump é só abrir o `index.html` no navegador.
